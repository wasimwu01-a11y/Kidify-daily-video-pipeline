# GTA 6 footage for the Tokyo Girl edits

Put official GTA 6 footage here. The daily workflow picks from it at random.

- **Trailer clips** (`.mp4`): download from https://www.rockstargames.com/VI/media.
  Short cuts of 10–60 s work best, and each file must be under 100 MB (GitHub's limit).
- **Screenshots** (`.jpg` / `.png`): from the same page. These get a slow zoom.
- **After launch (19 Nov):** add your own gameplay recordings here too.

Audio in these files is ignored. The edits are exported silent and you add the
official Tokyo Girl sound inside TikTok.
